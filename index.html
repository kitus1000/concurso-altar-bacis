💾 Guardado Permanente y Publicación en GitHub

Todos los equipos, fotografías y lugares de premiación se guardan automáticamente en este navegador. Además, puedes descargar el archivo oficial datos_equipos.json para respaldarlo o subirlo a tu repositorio de GitHub para que todos vean los mismos datos desde cualquier celular o computadora.

💡 ¿Cómo actualizar los datos públicos en GitHub Pages?
  1. Registra tus equipos, sube sus fotos y asigna los ganadores del podio aquí en la página.
  2. Haz clic en «Descargar archivo actualizado (datos_equipos.json)».
  3. Guárdalo dentro de la carpeta del proyecto (reemplazando datos_equipos.json) y haz Commit & Push en GitHub Desktop.
